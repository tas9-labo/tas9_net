About

  • 2002年ゲーム業界へ。3DCGデザイナーとして下積みから
  • 2009年モデラーからモーションデザイナーへ
  • 2019年フリーランスとして独立（屋号 +9）
  • 2025年OCA大阪デザイン＆テクノロジー専門学校 講師を兼任

モーション制作（手付け・キャプチャ）や品質管理・進行を、業務委託・リモートで承ります。

下積みから始め、モデラー、モーションデザイナー、品質管理・進行のリードを経て独立。
独立後は大作アクションのバトルモーションを手掛けながら、制作の道具（ツールやアプリ）も自分で作るようになりました。
いまは京都と長野を行き来し、制作・教育・AI活用をひとつの暮らしの中で回しています。

AI & Making

自分の知識と経験を AI に注ぎ、人に届く形に設計する——これを「AIナレッジデザイナー」と名付けています。

授業の教材やリグ・Maya ツール、制作現場で使う MotionBuilder ツール、業務用の Windows アプリまで、必要なものは自分で作ってきました。
いまは、思考を注いだ AI システム「佑」と、経理や記録の裏方から note の執筆までを分担しています。

主な開発言語

  • Python
  • Dart / Flutter

Python は Maya・MotionBuilder のツール、Dart / Flutter は Windows・Android アプリに使っています。
